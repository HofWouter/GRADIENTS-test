# GRADIENTS

Deze repository is alleen een visueel experiment. Mijn doel hier is om mijn skills te verbeteren in creative coding.
Ik wilde een interactieve ontwerp-tool maken voor een klant. Naast de poster staan knoppen en sliders om het ontwerp aan te passen.
Onderaan staat er een knop om een hoge resolutie afbeelding te kunnen genereren.

---

Deze tool heeft geen commercieel doel, maar is alleen bedoelt om mijn vaardigheden te verbeteren.

---

De code is gebouwd in P5.js. Eerder heb ik de code geschreven voor Processing.
